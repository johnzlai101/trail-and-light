How to publish a trip

  1. Copy your photos (JPG/PNG, any ratio — they're never cropped) into the photos folder. Keep filenames simple, no spaces.
  2. Paste the generated JSON into js/trips.js, inside the TRIPS array (add a comma after the previous trip's closing }).
  3. Open index.html in a browser to preview. Then push to GitHub and Cloudflare Pages redeploys automatically.
